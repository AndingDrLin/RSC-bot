# 研究方法与依据

> 回答两个问题：**① 策略是从哪来的？② 会不会拿实盘当训练集？**

---

## 0. 一句话结论

**实盘不学习，只验证。** 策略的知识来自历史数据和公开研究，实盘只承担三件事：验证执行链路、估计真实摩擦（滑点/拒单/成交率）、监控策略是否偏离回测。任何"边跑边调参"的做法在本项目中被禁止，理由见 §1。

---

## 1. 为什么不能在实盘里"学"

### 1.1 样本量根本不够

| 口径 | 数量 |
|---|---|
| 全市场标的 | 1638 |
| 行情频率 | 60 s / tick |
| 一天的可交易 tick | 1440 |
| 一天的全市场观测 | ~236 万条 tick |
| **但独立交易机会**（一个策略在一个标的上的一次进出） | 每天 **10–50 次** |
| 30 天累计 | 300–1500 次 |

一个中等复杂度的策略（10 个以上参数）需要至少 10 倍于参数量的**独立**样本才能可靠估计。1500 次机会里，扣掉重叠、相关性、非平稳，有效独立样本可能只有 100–200 个。

**结论**：实盘 1 个月的数据，连一个 3 参数策略都验证不了，更别说训练。用实盘数据调参 = 在噪声上做梯度下降。

### 1.2 市场是非平稳的

RSC 的价格锚定真实市场（Yahoo / Coinbase / OKX），但：
- 延迟品种（37 个）的价格是 15 分钟前的
- 交易时段、费率、活动（久留美）会变
- 其他玩家的行为会改变流动性

**任何在样本内拟合出的参数，在下一个 regime 都会失效**。这是量化行业公认的失败模式，见 Bailey & López de Prado (2014) 对"回测过拟合"的量化分析。

### 1.3 我们真正要"学"的东西

| 对象 | 学习方式 | 数据来源 |
|---|---|---|
| 策略结构（用哪个信号） | 文献 + 离线回测 | 历史 K 线 |
| 参数（窗口、阈值） | walk-forward，样本外 | 历史 K 线 |
| 摩擦（滑点、拒单率） | **实盘小额** | 真实成交 |
| 执行质量（是否按预期成交） | **实盘小额** | 真实成交 |
| 策略是否失效 | 在线监控（CUSUM / PSI） | 实盘 + 回测对比 |

实盘数据的正确用途是**最后一列**，不是第一列。

### 2.3 行业资料（方法论的来源）

| 来源 | 可迁移的要点 |
|---|---|
| **幻方量化**（公开演讲/采访） | ① 因子挖掘自动化（不是手工一个个试）；② 多模型集成而非单模型；③ 算力/数据基础设施先行；④ 用深度学习做**特征**而非直接预测价格 |
| **AQR** 的 trend following 系列白皮书 | 趋势策略在 60+ 市场的稳健性；波动率目标化是收益/风险比的主要来源 |
| **Two Sigma / Man AHL** 公开访谈 | 执行成本建模优先于信号精度；组合层风控 > 单策略风控 |
| **中国量化私募公开材料**（九坤、明汯） | 高频因子的衰减速度；换手率与容量的权衡 |

> 注意：幻方的**具体模型**没有公开，公开的是方法论。任何声称"复现幻方策略"的说法都不可信。我们能迁移的是**流程**：因子工厂 → 多模型 → 组合优化 → 执行。

## 3. 本交易所的"高频"边界（必须接受的现实）

| 约束 | 数值 | 后果 |
|---|---|---|
| 行情频率 | **60 s / tick** | 无法做 tick 级信号；最小决策周期 1 分钟 |
| 请求限频 | **30 次/分钟**（下单+行情合计） | 每分钟最多 ~20 次交易动作；全市场扫描必须靠缓存 |
| 订单类型 | **只有市价单** | 无法挂单赚价差；无法做被动成交 |
| 费率 | FX 1 bp、美股 5 bp、crypto 10–20 bp（**每边**） | 往返成本 2–40 bp，决定最低持仓周期 |
| 延迟品种 | 37 个标的延迟 15 分钟 | 这些市场只能做日级策略 |

### 3.1 成本决定频率（最重要的一张表）

| 品种 | 往返成本 | 盈亏平衡所需单次毛利 | 可行持仓周期 |
|---|---|---|---|
| **FX** | **2 bp** | 3 bp | **秒–分钟级**（唯一可做高频的品种） |
| 美股/指数/贵金属 | 10 bp | 12 bp | 小时–日级 |
| 港股/A股/日股/欧股 | 20 bp | 25 bp | 日级 |
| crypto | 20–40 bp | 25–50 bp | 小时级 |

**结论**：所谓"尽可能多且快"，在本交易所只能是：
- **FX 上做真正的分钟级**（费率 1 bp，且 24×5 连续）
- **crypto 上做小时级**（24×7，但费率 10–20 bp）
- **股票上做日级/隔夜**（受时段 + 20 bp 限制）
- **广度**上覆盖尽可能多品种，而不是在单一品种上提高频率

这不是妥协，是费率结构决定的。任何声称能在 20 bp 成本下做分钟级股票高频的方案，数学上不成立。

## 4. 三轨实验设计

```
┌─────────────┐   ┌─────────────┐   ┌─────────────┐
│  离线回测    │   │   paper     │   │  live 小额   │
│ (历史数据)   │   │ (实时不下单) │   │ (真实成交)    │
├─────────────┤   ├─────────────┤   ├─────────────┤
│ 策略是否有效 │   │ 代码是否正确 │   │ 摩擦有多大    │
│ 参数是否稳健 │   │ 时延是否可接受│   │ 成交率/拒单率 │
│ 样本外表现   │   │ 状态机是否自洽│   │ 滑点分布     │
└─────────────┘   └─────────────┘   └─────────────┘
      ↑                                     │
      └──────── 发现的偏差回写 ──────────────┘
                （只回写执行假设，不回写策略参数）
```

**红线**：live 的成交数据只能用来更新"执行模型"（滑点、成交率、拒单率），**不能**用来重新拟合策略参数。后者必须回到离线数据做 walk-forward。

## 5. 防过拟合纪律（写进 CI）

1. 任何策略报告必须包含 **样本外** 结果，样本内只作参考。
2. 参数搜索用 **walk-forward**（滚动窗口），禁止全样本网格搜索。
3. 多重检验：同时测试 N 个变体时，阈值按 Bonferroni 或 **Deflated Sharpe Ratio** 调整。
4. 报告 **DSR** 和 **PBO**（回测过拟合概率），不只报 Sharpe。
5. 交易次数 < 100 的回测结果不作为上线依据。
6. 跨市场验证：同一策略在 FX、crypto、指数上分别跑，若只在单一市场有效，视为过拟合嫌疑。
7. 任一策略上线前，必须有 **"失效判据"**（例如滚动 60 日 Sharpe < 0 且回撤 > 2× 历史最大回撤 → 自动降仓/下线）。

## 6. 本项目采用的策略族（与文献的对应）

| 族 | 信号 | 市场 | 文献 | 预期频率 |
|---|---|---|---|---|
| T1 时序趋势 | 多窗口动量 + ATR 止损 | FX、crypto、指数 | Moskowitz 2012; Hurst 2017 | FX 分钟级、crypto 小时级 |
| T2 截面动量 | 20 日收益排序 | 美股、欧股 | Jegadeesh & Titman 1993 | 日级 |
| T3 配对/价差 | 协整残差 z-score | ASML 双挂牌、指数 vs ETF | Gatev 2006; Avellaneda 2010 | 小时–日级 |
| T4 波动率管理 | 目标波动率缩放 | 组合层 | Moreira & Muir 2017 | 日级再平衡 |
| T5 事件/活动 | 久留美活动期的 FX 波动率抬升 | FX | 无（本项目特有） | 事件驱动 |

高风险卫星 = T1 在 FX 上开高杠杆（≤100x）+ T5；稳健核心 = T2 + T3 + T4 低杠杆。
